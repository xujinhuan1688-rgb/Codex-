# 03｜镜头语言、摄影参数与光影设计

## 镜头语言：执行语言，不是修辞

每个镜头必须同时回答：为什么这样拍？服务哪段剧情？哪种表演被看见？参数为什么这样设？

### 景别功能

- 大远景：交代地理与规模。
- 远景 / 全景：人物与空间关系。
- 中景：人物行动与关系表达。
- 中近景：台词与微表情兼顾。
- 近景：情绪聚焦。
- 特写 / 极特写：生理细节、关键情绪、关键物件。

### 运镜功能与强度

- 缓慢推进：聚焦、压近、情绪靠近。
- 后拉：疏远、揭示、人物被空间吞没。
- 平移：关系并置、群像浏览、空间展示。
- 轻微环绕：暧昧、压迫、失衡、仪式感。
- 固定机位：让表演承担主体。
- 手持：主观、纪实、危险感。
- 轨道 / 稳定器：控制性、工业感。
- 运动强度必须标注：静态 / 克制 / 渐进 / 短促，禁止无意义大幅运动制造「大片感」。

### 轴线与景别衔接

- 对话 / 对视 / 对抗场景先立轴再拍；反打不得无理由越轴。
- 避免连续多个一模一样的景别机械拼接。
- 长台词用 2-3 镜承接；关系拉扯优先中景 → 中近景 → 反应近景；悬疑揭示优先建立镜 → 观察镜 → 发现镜 → 压迫镜 → 停顿镜。

## 摄影参数基线

每镜固定写 fps / 快门角度 / 焦段 / 光圈 / ISO / 白平衡。

- 文戏：24fps、180°快门、35/50/85mm 为主、T2.0-T2.8、ISO 800、WB 按主光源锁定。
- 动作戏：24fps 或按需升格、90°-180°快门、24/35/50mm、景深略深防丢焦。
- 特效戏：参数服从特效可视性与脸部稳定，避免过浅景深盖掉能量体。
- 升格（慢动作）只用在打击点 / 关键情绪 / 关键揭示，不得整段滥用。

## 光影设计

### 设计顺序

1. 定光源动机（光从哪来、为什么）。
2. 定人物受光方式。
3. 定背景与空间层次。
4. 定气氛强化。

### 光源动机（叙事层的「光从哪来」）

可用具体来源词：窗外天光、门外雨光、烛火、台灯、顶灯、霓虹 / 街灯、法术 / 特效自发光、月光、火光、屏幕光。但光影关系必须写成可验证的摄影参数，不得只写「自然光 / 冷暖对比 / 高光克制」三四个潦草词。

### 光影八要素（每镜 / 每场的「光影设计」必须覆盖）

1. **方向**：正面 / 侧前 / 侧向 / 侧后 / 顶部 / 包裹式环境光；可写由画内一侧向另一侧衰减。
2. **高度与角度**：平视、略高、低角度掠射、顶部下压，符合时间与空间逻辑。
3. **软硬**：柔和散射 / 半硬定向 / 硬朗切割 / 软硬混合，并说明阴影边缘与过渡速度。
4. **主辅层级**：主光、环境补光、背景亮度的相对层级；可用「弱补光、负补光感、背景低一级曝光」。
5. **光比与曝光**：低 / 中 / 高光比；说明主体曝光与背景压暗 / 抬升关系，禁止全剧一律高光比。
6. **色温分区**：中性统一或冷暖分离，及冷暖过渡方式；禁止机械「青橙对撞」。
7. **高光与阴影**：高光落点是否集中、滚降是否柔和、是否接近但不触顶；阴影渐变、暗部是否可读、黑位是否保留色彩。
8. **空气传播**：光线在空气中的衰减 / 扩散 / 雾化 / 通透，前中后景是否通过亮度与空气层次分离。

### 技术底座（全局锁定，逐镜不重复长段）

`电影级质感，超写实，极致逼真，真人实景拍摄，杜绝游戏 CG 感，杜绝动作僵硬，真实光影，电影级肤色还原，亮部滚降自然，暗部层次可读，8K 细节，真实空间比例，真实透视，真实空气层次，真实镜头光学表现，适度电影颗粒，杜绝概念渲染感，杜绝舞台化布光，杜绝塑料肤质，杜绝过度锐化，杜绝不合理物体生成。`

### 污染词黑名单

禁止出现：Unreal Engine、Octane Render、ray tracing、3D render、concept art、digital painting、游戏过场、CGI、建筑可视化、二次元、抽象视觉实验。禁止用「物品+发光 / 材质+高光」把光影责任推给道具；「大片感 / 高级感」必须由可验证的摄影关系构成，不得直接作为替代词。

### 空间与情绪光影适配

- 室内压抑：中高光比、单侧主光或顶部下压、负补光、暗部保留微色、长焦压缩、封闭构图。
- 室内温情：低至中光比、柔和包裹、阴影柔缓、暖灰与中性过渡、开放构图。
- 夜间：低照度但不欠曝、冷色环境域与有限暖色域分层、高光集中不过曝、暗部可读不死黑。
- 职场 / 制度空间：均匀冷白环境光 + 轻微侧向塑形、中光比、中性偏冷、对称构图、稳定器缓移。
- 医院 / 走廊：顶部均匀光 + 冷白环境、中低光比、轻微广角、秩序构图、低饱和冷灰。
- 校园 / 青春：自然日光、低至中光比、柔和散射、清透中性、轻微广角、开放明亮。
- 雨天 / 潮湿：阴天漫射、低至中光比、雾化高光、暗部不死黑、空气扩散明显、沉静压抑。
- 回忆 / 幻想：低反差柔光、柔焦边缘、轻微光晕、黑位略抬、记忆颗粒、漂浮构图，仍保持真人实拍光学感。
- 对峙 / 复仇高压：半硬定向、中高光比、侧向或顶部塑形、阴影更清晰、背景受控、镜头运动节制。
- 结尾 / 和解：自然降低光比与反差、柔侧前或包裹光、阴影变软、暖灰或中性、空气通透。

## 相邻场连续性

相邻场次的时间、曝光、色温、光线方向必须连续；只有叙事阶段明显改变时才允许显著转向。禁止「同上 / 同前 / 延续上一场 / 略」。
