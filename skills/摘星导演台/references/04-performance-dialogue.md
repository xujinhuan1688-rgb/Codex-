# 04｜表演调度、微表情与台词设计

## 核心原则

分镜不是只拍「发生了什么」，而是拍清「角色如何完成这段戏」。禁止只写「女主悲伤 / 男主愤怒」，必须写可演、可看、可被 Seedance 2.5 理解的行动与表情。

## 每镜表演至少回答

- 角色做了什么动作？为什么这么做？
- 说这句台词时是什么状态？
- 面部表情是怎样的？呼吸节奏如何？
- 眼神看向哪里？身体重心是否变化？

## 表演优先级（从细节到大体）

1. **微表情**：眼神锁定 / 偏移、眉心轻压、唇线收紧、下颌绷住、鼻翼轻动。
2. **呼吸**：停顿、变浅、变急、长吐气、屏息。
3. **肩颈与手**：肩背绷起、颈部发紧、手指缩紧、袖口被无意识抓紧、指尖轻颤。
4. **体态与重心**：站稳、后撤半步、倾身靠近、身体先停眼神先动、重心下沉。

## 台词强制字段

有台词必写：语气 / 情绪 / 节奏 / 重音 / 面部表情。

示例：

`角色名：“原台词……”【语气：压低｜情绪：戒备｜节奏：慢｜重音：关键词｜面部表情：眉心微压、唇线收紧】`

## 内心独白处理

内心独白不得只放文字，必须有视觉动作对应：独白 + 呼吸停顿 / 眼神锁定 / 手部无意识动作 / 静止不回头。优先「镜头先服务情绪，再补独白」。

## 台词设计（编剧层）

- 精简 + 信息密集：砍掉冗余修饰与寒暄。
- 功能分层：推剧情 > 塑人物 > 调节奏 > 埋伏笔 > 做呼应。
- 题材语感：古装 / 奇幻符合时代语感与世界观；情感题材重细腻与节奏；轻喜剧笑点从人物和情境自然生发。
- 潜台词：写「话外之意」，不写满。让表演承担未说出口的部分。
- 语言指纹：句长、节奏、称谓、礼序、用典密度、常用意象、回避方式、威胁方式、失控标志、禁用现代词。高阶不等于文言，魔修不等于邪笑，妖族不等于统一异域腔。验收：遮住角色名后，多数台词仍能凭指纹判断说话者。
- 口诀 / 咒语（玄幻 / 仙侠）：4-12 字、可呼吸、可表演、有重音，与功法机制一致；长诀拆为起势、转势、落势；禁止无功能堆砌「天地玄黄、急急如律令」。验收：口诀能在目标镜头时长内自然念完。

## 台词与镜头配合

- 一句台词过长可跨镜承载，但不得丢失语义、不得删句。
- 画外音与画内音必须区分清楚。
- 不得用声音摘要代替原台词；台词必须和表演字段配套。

## 精修记录（优化台词时保留）

`原句｜问题｜精修句｜潜台词｜表演停顿｜自然语速｜事实是否保持`——精修后事实与剧情不得漂移。
