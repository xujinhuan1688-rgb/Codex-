# 01｜工作流与多类目题材路由

## 完整状态机（内部不可跳步）

### 第 0 步：输入校验

必填：剧本正文（含动作 / 台词 / 内心独白 / 场次信息）。全局风格缺失时可用「从剧情与题材推断」兜底，但必须在输出中标注「本次未锁定外部风格，以下为推断方案」。缺剧本则先提示，禁止空写分镜。

可选：角色/场景/道具图、参考视频、画幅、单组时长要求（默认 30 秒）。

### 第 1 步：逐字读剧与覆盖建档

- 逐字读完，不做摘要式扫读。
- 拆分为：集 / 场 / 段 / 句 / 动作 / 台词 / 内心独白。
- 建立「剧情覆盖索引表」：事件、台词、内心独白、关键动作、道具、空间转换，逐条映射到镜头编号。
- 打标签：场景、时间、角色、情绪、动作、特效、声音、道具、风险（跳轴 / 群像 / 动作 / 光源不清）。

### 第 2 步：题材识别与路由

判断：题材、子题材、核心卖点、关系结构、表演强度、动作/特效强度、视觉风格倾向，再按下表路由节奏与视觉策略。

| 题材 | 情绪引擎 | 节奏策略 | 视觉基调 | 常见风险 |
| --- | --- | --- | --- | --- |
| 都市情感 / 家庭伦理 | 关系张力 + 身份落差 | 快冲突、慢拉扯 | 冷峻写实 / 冷暖现实 | 群像反应堆叠 |
| 复仇爽剧 | 被压→反杀的信息差 | 高频反转、强爽点 | 高压现实 / 半硬定向光 | 情绪过载、多人同镜 |
| 甜宠 / 轻喜剧 | 暧昧 + 反差 + 误会 | 轻快、留糖 | 明亮生活 / 柔光低对比 | 笑点依赖台词堆砌 |
| 悬疑犯罪 | 递进悬念 + 核心反转 | 先钩子后解释 | 冷峻自然主义 / 低照度 | 抽象描述、一镜到底 |
| 古装权谋 | 权力 + 礼序 + 潜台词 | 文戏占主、动作点睛 | 东方肃穆写实 | 越轴、站位逻辑 |
| 玄幻修仙 | 规则代价 + 境界压制 | 先立世界再斗法 | 东方奇幻写实（禁 CG 感） | 战力崩坏、特效乱飞 |
| 武侠 / 打斗 | 力量传导 + 攻防博弈 | 一招一镜、升格点缀 | 粗粝写实 / 侧逆塑形光 | 「二人激烈打斗」空话 |
| 青春校园 | 成长 + 治愈 | 自然流、情绪慢燃 | 日系自然光治愈 | 过度滤镜化 |

### 第 3 步：红果式黄金开场与主线判断

按 `02-redfruit-design.md` 锁定：五要素开场、短剧版起承转合、一句话主线、大期待最晚第 2 集直白、单集前中后 30 秒节奏、情绪点楼梯。

### 第 4 步：全局视听方案

先定「光影圣经」（全剧统一影像路线 + 逐场光影八要素），再定镜头基线、表演基线、特效基线与声音规则（无 BGM、无内嵌字幕默认开启）。落到每个 30 秒组时只引用全局方案，不重复长段技术底座。

### 第 5 步：30 秒固定组分镜生成

按 `08-seedance25-storyboard.md` 输出。每组 30 秒、组内无时间轴、逐镜强画面感。组数由剧情决定；一组装不下时，续写下一组并做连续性锁。

### 第 6 步：三轮审核

按 `07-continuity-audit.md` 执行：剧情覆盖 → 视听连续性 → Seedance 2.5 可执行性。任一不过即修正，三轮通过才交付。

### 第 7 步：交付

按需输出：分镜正文 + 审核结论 + Docx（结构化，可直接复制到文档工具）+ Seedance 2.5 生成提示词。

## 门控规则

- 「分阶段」：读剧诊断 → 题材路由 → 全局方案 → 30 秒组分镜，每步等确认。
- 「直接成稿」：内部完成 0-4 步，直接输出分镜主稿。
- 「只优化某环」：只进对应环节。

## 失败兜底

- 题材不明确：按「关系结构 + 情绪强度」选最近路由，并说明推断依据。
- 无资产图：按剧本逻辑做分镜，不暂停。
- 单组 30 秒装不下：跨组续写，禁止删剧情或删台词。
- 检索不到同题材爆款：降级为「相近题材 + 相近情绪表达」，只借鉴视听方法。
