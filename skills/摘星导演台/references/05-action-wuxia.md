# 05｜打斗动作与武术设计

## 原则

动作戏必须讲清：谁先动、怎么动、力从哪来、打到哪里、对方如何反应、镜头如何服务动作。禁止「二人激烈打斗 / 一场混战 / 刀光剑影」这类无画面空话。

## 动作拆解最小单元

`起势 → 发力 → 接触（或接近接触）→ 结果 → 反应 → 回位 / 连招衔接`

每击必须给出明确动作动词（格挡、下劈、横扫、直刺、侧踢、绞缠、卸力、借力、贴地滑步）。

## 力量传导与身体逻辑

- 力从脚→腰→肩→臂→兵器或拳，写清重心与借力。
- 武器位置必须前后镜连续；受伤后动作必须降速或变形。
- 对手受击要有明确反应（后仰 / 踉跄 / 单膝跪地 / 兵器脱手 / 借势翻滚）。
- 兵器与身体关系：距离、持械手、刃口方向、收势动作。

## 武术门类语感（用于招式命名与路径）

拳掌（冲拳、劈掌、推掌、擒拿）、腿法（鞭腿、侧踹、扫堂）、身法（闪、腾、挪、卸力）、兵器（剑走轻灵、刀走厚重、棍扫一片、枪扎一线）。招式差异来自动作路径、媒介、空间控制与代价，不来自换颜色。

## 动作镜头设计顺序

1. 先设计动作逻辑。
2. 再设计机位。
3. 再决定跟拍 / 俯拍 / 特写。
4. 再决定慢动作 / 升格 / 特效辅助。

常用序列：预备对峙中景 → 发力跟进镜 → 打击点特写 → 反应镜 → 空间再建立镜 → 连招接镜。

## 动作戏强制约束

- 不得只写动作，必须写清招式目标与动作路径。
- 复杂打斗拆成多个稳定镜头，不把三连招 + 特效爆发 + 群像反应塞进同一镜。
- 镜尾必须能接下一招（停在明确发力点 / 受击点 / 回位点）。

## 仙侠 / 玄幻斗法镜头（补充）

- 斗法：先建立空间与战术信息，再设计前摇、气机、接触 / 反制、结果与反应。
- 御剑：明确高度、速度、方向、身体受力、衣物反馈和地标位移；避免无目标环绕与永恒慢动作。
- 渡劫：雷劫不是连续闪电，建立天象预兆 → 规则锁定 → 人物准备 → 阶段升级 → 承受结果 → 余韵。
- 修炼悟道：用感知边界、重复动作的细微变化、环境响应和焦点转换表现内在变化，避免默认盘坐闭眼金光环绕。
- 文戏权力：通过座次、门槛、礼序、视线、法宝反应与空间距离承载权力和潜台词，不默认正反打。
