# 06｜玄幻修仙世界观与特效设计

## 修炼境界体系（每境界一张表）

每个境界用同一张表定义：名称、核心变化、感知范围、身体承载、规则权限、寿元、资源需求、突破条件、失败结果、外显征象、下位压制、高位限制。

设计原则：

- 境界差至少影响信息 / 承载 / 控制 / 规则权限之一，不只增加破坏力。
- 突破同时改变能力、社会身份和风险。
- 越级胜利必须来自信息差、克制、地利、代价或预先布局，不能只靠意志爆发。
- 同阶因道统不同形成战术差异。

压力测试四问：低阶主角面对高两阶敌人有没有合理逃生而非击杀路径？灵气断绝时哪些职业仍可行动？连续突破是否绕过寿元 / 心境 / 资源 / 身体承载？最强者为何没有直接解决所有社会问题？

## 战力与规则一致性

建立事件表：参与者境界、可用功法、剩余资源、伤势、地形、已知情报、克制、胜负结果。

越级结果至少满足两项：明确克制、信息优势、预置阵法 / 法宝、对手受限、环境优势、重大代价、胜利目标并非击杀。

漏洞扫描：忘记已有能力导致降智；法宝同时出现在不同地点；伤势与灵力无恢复过程即归零；高阶能力能解决前文全部问题却从未使用；反派只在主角准备完成后行动；临时新增天道例外只服务一次反转。

## 特效设计

### 原则

特效服从剧情与表演，不可脱离角色行为独立乱飞；必须与表演、光影、空间融合，并同步照亮人物。

### 特效分类

法术释放、能量聚集、剑气 / 刀光、粒子消散、变身、空间扭曲、时间停滞 / 时间切片、爆裂冲击、环境级特效（雨、风、尘、火花、烟）。

### 特效描述最低字段

每一处特效至少写：触发者、触发动作、出现位置、颜色 / 质感、强度、传播路径、对环境影响、对人物受光影响、收束方式。

### 特效与灯光同步

特效是否成为临时主光源？特效颜色是否改变人物边缘光？特效消失后光线如何收束？

### 无特效场景

必须明确标 `特效：无特效`，不得含糊。

## 常见失败写法

- 写「华丽法术爆发」但没写从哪来、如何收。
- 特效强到盖住人物表演。
- 特效出现却没有照亮人物。
- 特效结束后画面状态没交代。

模型明显不适合高复杂特效时：保留特效信息，降低单镜复杂度，拆为「前奏 / 触发 / 爆发 / 收束」多镜。
