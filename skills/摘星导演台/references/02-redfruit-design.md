# 02｜红果爆款设计思维

核心立场：把「我觉得好看」换成「平台为什么选、制作方为什么敢拍、观众为什么留下来」。免费平台看「留存坎」不是「付费坎」，观众随时划走，情绪要更快拉升并全程维持。

## 黄金开场五要素

1. **清晰人设**：不靠旁白靠事件。例：被岳母当众泼茶骂「废物」 > 「我是个赘婿」。
2. **明确主线**：复仇 / 翻身 / 守护 / 找真相 / 考功名，一句话说清；越具体越有追剧欲。
3. **强烈困境**：即时、具体、有压迫的危机（逐出家门 / 修为被废 / 亲人垂危 / 生死威胁）。
4. **持续情绪推进**：密集反转与情绪转换，让观众坐过山车。
5. **有效信息密度**：台词同时推剧情、揭关系、露矛盾、强人设。

### 短剧版起承转合

- 起：高能切入、制造冲突、抓眼球。
- 承 + 转：推进行动、建立关系与主线、升级冲突、推向小高潮。
- 合：悬而未决（话到一半戛然而止 / 动作推到高潮定格 / 真相呼之欲出未揭晓）。

## 主线三原则

- 定调：告诉观众这是哪类故事（复仇=紧张压抑对抗，甜宠=轻松温暖带糖）。
- 串联：把独立情节串成一条线（收集证据 → 假装示弱 → 设局反杀，全指向「寿宴离婚曝光渣男」）。
- 聚焦：有限篇幅做减法。大期待最晚第 2 集直白展现，不藏不绕。

## 节奏与留存

- 三段式（80-100 集）：1-10 集黄金窗口（立主线亮看点）→ 11-30 集稳固发展（主线实质推进）→ 31-80 集高潮收束（伏笔揭晓、多轮反转）。
- 单集（1-3 分钟）：前 30 秒定生死（给理由停下）→ 中间推进故事不注水 → 最后 30 秒留钩子（强悬念 / 未完成动作 / 意味深长台词 / 突然反转）。
- 30 秒固定组对应「单集节奏」的最小执行单元：每个 30 秒组都必须自带「一个钩子 + 一个推进 + 一个未完成落点」，不能是一段平淡过场。

## 期待 / 悬念 / 钩子

- 期待是树干（方向），悬念是枝叶（张力），钩子是根茎（每集推力）。
- 大期待 = 主角终极目标（戏眼）；小期待 = 一步步台阶。
- 先给大期待再谈结尾钩子；没有核心期待，所有钩子都是无本之木。

## 情绪点楼梯

- 每集一个小情绪点；约 8-10 集一个大情绪点（集中兑现前面积累）。
- 困境情节三原则：时长要控制（简洁、迅速转向转机）；要留希望（暗示反击准备 / 潜在助力）；针对性要强（困境来自清晰对立角色或明确矛盾）。

## 台词打磨（与表演层联动）

- 精简 + 信息密集：每秒都贵，砍掉冗余修饰与寒暄，只留核心对白。
- 功能分层：推动剧情（第一要务）→ 塑造人物 → 调节奏 → 埋伏笔 → 做呼应。
- 题材语感：古装 / 奇幻符合时代语感与世界观；情感题材重细腻与节奏；轻喜剧笑点从人物和情境自然生发。
- 自检三问：以他的性格 / 身份 / 情绪 / 情境会这样说吗？朗读分饰角色是否流动？砍掉三分之一后核心信息还在吗？

## 落地自查（过稿三关）

1. 内容关：一句话说清内核，读者视角检验吸引力。
2. 落地关：场景 / 预算 / 审核风险放大镜排查。
3. 完整关：主线 / 节奏 / 人设统一，无逻辑硬伤。

**少写「心理」，多写「行为」**：写导演演员能执行的行动与表情，不写「心碎了一地」。能通过表演呈现的内心活动不用 OS，能通过对白表达的不用 VO。
