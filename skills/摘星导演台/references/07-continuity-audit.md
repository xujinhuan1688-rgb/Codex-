# 07｜连续性、防跳轴与三轮审核

## 连续性原则

任何镜头都必须连续回答：人在哪、面朝哪里、从哪来、正要去哪、手里拿着什么、光从哪来。

必查项目：服装、发型、光源方向、人物站位、道具、运动方向、视线方向、门窗桌椅屏风等固定空间物位置。

## 防跳轴规则

1. 先立轴。
2. 对话场固定视线方向。
3. 动作对抗场固定攻防方向。
4. 未经桥接镜不得越轴。
5. 必须越轴时，先给中性镜 / 环绕桥接镜 / 明显空间转换镜。

高风险：对话反打突然反向、入画方向前后变、上一镜看右下一镜无过渡看左、特写切特写没有空间提醒。

## 镜尾稳定原则

镜尾必须停在明确动作点 / 视线点 / 情绪点，不抖不漂，能接下镜；并说明下一镜最适合怎么接。

## 三轮审核

### 第一轮：剧情覆盖审核

反查：剧情事件、台词、内心独白、关键动作、道具与空间变化是否全部覆盖。输出漏项列表与修正。

### 第二轮：导演 / 摄影 / 连续性审核

检查：每镜是否以角色表演为中心、景别与情绪是否匹配、参数是否明确、轴线是否稳定、灯光动机是否清楚、声音层是否完整、特效状态是否明确、镜尾是否稳定可接。输出风险镜头清单与修正。

### 第三轮：Seedance 2.5 可执行性审核

检查：是否单镜过载、是否抽象描述过多、是否多人复杂动作堆叠、是否存在强一致性风险、是否无法被模型稳定理解。输出失败风险清单、拆镜 / 降载 / 重写建议与修正。

## 16 项质量门禁（交付前逐条过）

1. 是否遗漏剧情事件。
2. 是否遗漏关键台词。
3. 是否遗漏关键内心独白。
4. 是否有镜头只写氛围、不写表演。
5. 是否有镜头写了镜头语言但无剧情动机。
6. 是否每镜都有明确动作动词。
7. 是否每镜都有微表情或体态。
8. 是否有跳轴风险。
9. 是否有镜尾不稳。
10. 是否有特效未明确（有 / 无）。
11. 光影八要素是否写全且不冲突。
12. 摄影参数是否写死而非模糊建议。
13. 是否存在 Seedance 2.5 超载描述。
14. 是否无 BGM、无内嵌字幕默认执行。
15. 是否每个 30 秒组自带「钩子 + 推进 + 未完成落点」。
16. 是否组内出现时间轴约束（禁止）。

任何一项不过即修正，全部通过才允许交付。
