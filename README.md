# 摘星导演台 · Codex 技能

一套面向多类目中国竖屏短剧的综合编剧与导演分镜系统，适配 Seedance 2.5。

## 能力

- 输入完整剧本 → 深度读剧 → 题材路由 → 红果式黄金开场 → 30 秒固定组分镜。
- 每个 30 秒分镜组完全自包含、七段锁定格式（角色·场景资产提示词 / 主体与风格锚点 / 场景与环境 / 专业运镜与光影基调 / 动态分镜脚本 / 台词与字幕 / 负面描述）。
- 无时间轴、无镜头时长、无道具资产、画幅由用户生成视频时自定义；台词拼音发音、口型 100% 咬合。

## 目录结构

```text
skills/摘星导演台/

```

## 安装方式

### 方式一：npx skills（推荐，全局安装）

```bash
npx skills add xujinhuan1688-rgb/Codex- -g
```

### 方式二：git 克隆后手动复制

```bash
git clone https://github.com/xujinhuan1688-rgb/Codex-.git
# 将 skills/摘星导演台 目录复制到 ~/.codex/skills/ 下
```

安装完成后，在新对话中技能会自动被发现，名称显示为「摘星导演台」。
